# Retail Sales Analysis & Data Preprocessing (EDA)

This project focuses on Exploratory Data Analysis (EDA) and data preprocessing on retail sales data using Python, Pandas, Matplotlib, and Seaborn.

## 📌 Project Overview
- *Data Preprocessing:* Cleaning and structuring raw sales data.
- *Exploratory Data Analysis (EDA):* Extracting key business metrics such as monthly sales trends, top-performing categories, and profit margins.
- *Data Visualization:* Creating intuitive dashboards using Seaborn and Matplotlib.

## 🛠️ Tools & Libraries Used
- *Language:* Python
- *Data Analysis:* Pandas, NumPy
- *Data Visualization:* Matplotlib, Seaborn

## 📂 Project Structure
- miniproject1.ipynb - Complete Jupyter Notebook containing code, charts, and key analytical insights.

## 📈 Key Insights
- Analyzed regional sales performance and product category trends.
- Visualized distribution patterns to identify revenue growth drivers.
